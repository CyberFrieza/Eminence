# Eminence

Jeu Commander Magic: The Gathering contre une IA — un seul fichier, hors ligne, pour Windows.

## Installation

1. Téléchargez l'installeur depuis la dernière version (page Releases).
2. Lancez-le (au premier lancement, Windows peut afficher SmartScreen : « Plus d'infos » → « Exécuter quand même » — l'application n'est pas signée).
3. Eminence.exe doit se trouver dans le même dossier que le fichier du jeu et le dossier Cards/.

## Mises à jour

Aucune action requise : à chaque ouverture, le jeu vérifie la dernière version publiée ici, la télécharge et l'installe tout seul avant de s'ouvrir. Sans connexion, il s'ouvre avec la version en place. Les sauvegardes ne sont jamais touchées par les mises à jour.
